# Caroling Chill Festival · Traducción en vivo

Página para proyectar subtítulos traducidos en tiempo real (Instituto Tlaquepaque).

- Abrir en **Google Chrome o Edge** (computadora), dar clic en **Iniciar** o presionar la **barra espaciadora** y permitir el micrófono.
- Teclas: `Espacio` iniciar/detener · `+` / `-` tamaño de letra · `F` pantalla completa.
- Requiere internet (reconocimiento de voz de Chrome + traducción).

Sitio estático: `index.html` + `logo.jpg`. En Cloudflare Pages no necesita comando de compilación; directorio de salida: `/`.
